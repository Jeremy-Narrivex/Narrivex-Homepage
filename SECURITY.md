# Security Policy

## Supported Versions

Only the main branch (`main`) is actively maintained with updates and security fixes.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this website seriously. If you discover a security vulnerability, please follow these steps:

### How to Submit
* **GitHub Private Vulnerability Reporting:** Submit a report using GitHub's Private Vulnerability Reporting feature on this repository.
* **Email:** Alternatively, contact the maintainer directly via email.

### What to Include
* A description of the issue and its potential impact.
* Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
* Any relevant URLs or HTTP details.

### Response Process
* **Acknowledgment:** Expect an initial response within 48 hours.
* **Resolution:** Once verified, a fix will be deployed directly to `main`. Please refrain from publicly disclosing the issue until a fix has been published.
